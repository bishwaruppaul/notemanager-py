Features

P

Portable

Single executable, zero dependencies. No Python, no npm, no Docker. Runs on Windows, Linux, and macOS.

A

Auto-save

Debounced auto-save with a save-status indicator. Never lose a note.

M

Markdown

Write in Markdown with live preview. Three-panel layout: tags, notes, editor.

T

Tags

Organize notes with tags. Autocomplete, filter by tag, sidebar tag cloud.

6

6 Themes

Light, Sepia, Solarized Light, One Dark, Nord, Dracula. Saved across sessions.

S

Search

Full-text search across all notes. Results update as you type.

O

Offline

Everything runs locally. No internet, no cloud, no accounts, no telemetry.

F

Plain text

Notes are plain .txt files. Compatible with the original NoteManageR format. Sync with any cloud.

Quick start

  1. Download NoteManagerPy-Windows.exe from the latest release.
  2. Double-click the downloaded file.
  3. Open http://127.0.0.1:5000 in your browser.
  1. Download NoteManagerPy-Linux from the latest release.
  2. chmod +x NoteManagerPy-Linux
  3. ./NoteManagerPy-Linux
  4. Open http://127.0.0.1:5000.
  1. Download NoteManagerPy-macOS (or NoteManagerPy-macOS.app) from the latest release.
  2. chmod +x NoteManagerPy-macOS
  3. ./NoteManagerPy-macOS
  4. Open http://127.0.0.1:5000.
